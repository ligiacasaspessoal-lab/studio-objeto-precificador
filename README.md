# Studio Objeto · Precificador para embaixadores

Site público com o simulador de orçamentos para as lojas embaixadoras (`lojista.html`).

- Este repositório recebe apenas o arquivo publicado pelo build da base privada (`pre-os-so_licenciamentos`): não edite nada aqui à mão, a próxima publicação sobrescreve.
- A base (tabelas, custos, royalties, fichas) fica no repositório privado. Cada `push` lá dispara o workflow "Publicar simulador", que copia o `lojista.html` para cá.
- Endereço do simulador: `https://ligiacasaspessoal-lab.github.io/studio-objeto-precificador/` (o mesmo em `/lojista.html`). `?emb=ID` abre já com a loja cadastrada.
